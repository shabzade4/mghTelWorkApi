# سیستم جامع مدیریت هوشمند (mghTelWorkApi)

نسخه **۳.۷** — برنامه تحت‌وب (PWA) برای مدیریت مالی، وام، مخاطبین، کارها، یادداشت‌ها، تقویم شمسی و گزارشات.

## فایل‌ها

| فایل | توضیح |
|------|--------|
| `index.html` | برنامه اصلی (تک‌فایل) |
| `manifest.json` | تنظیمات PWA |
| `sw.js` | Service Worker برای حالت آفلاین |
| `schema.sql` | اسکریپت ساخت جداول Supabase |

## استقرار روی Vercel

1. این ریپو را در [Vercel](https://vercel.com) ایمپورت کنید.
2. Framework: Other / Static
3. Deploy

یا فایل‌ها را در ریشه پروژه قرار دهید.

## دیتابیس (Supabase)

1. پروژه جدید در [supabase.com](https://supabase.com)
2. SQL Editor → اجرای کامل `schema.sql`
3. از Settings → API آدرس و کلید `anon` را در اولین اجرای برنامه وارد کنید

## ورود پیش‌فرض

- کاربر: `admin`
- رمز: `admin`

پس از ورود، در تنظیمات ایمیل و موبایل بازیابی را ذخیره و رمز را تغییر دهید.

## امکانات

- مالی و وام (محاسبه اقساط ایران)
- مخاطبین + تماس / پیامک / ایمیل
- کارها و یادآورها
- یادداشت (عادی / رمزدار)
- تقویم شمسی + رویداد
- گزارش و خروجی PDF / اکسل
- تم و فونت فارسی متنوع
- واحد تومان / ریال
- ورود امن، رمزنگاری AES، بازیابی رمز
- بکاپ JSON کامل

استفاده شخصی / پروژه اختصاصی.
